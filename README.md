\# RetailPulse — Customer Intelligence \& Sales Analytics



\## Overview

RetailPulse is a data analytics project that explores online retail transactions to identify sales trends, top-performing products, country-level sales patterns, and customer purchasing behaviour.



\## Tools \& Technologies

\- Python

\- Pandas

\- Matplotlib

\- Jupyter Notebook



\## Project Objectives

\- Analyze sales trends over time

\- Identify top-performing products and countries

\- Explore customer purchasing behaviour

\- Perform RFM analysis for customer segmentation



\## Work Completed

\- Dataset exploration and data-quality checks

\- Duplicate identification and removal

\- Sales calculation

\- Country-wise and product-wise sales analysis

\- Monthly sales trend visualization

\- Initial customer analytics



\## Dataset

This project uses the UCI Online Retail dataset. The raw dataset is stored locally and is excluded from this repository.



\## Project Status

In progress — customer segmentation and further analysis are being developed.
